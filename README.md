# Validere

Validere is an enterprise environmental operations and emissions data management platform for the energy industry — emissions reporting, methane management, EHS compliance, asset management, and production accounting for upstream, midstream, refining, utility, and CCUS operators.

- Website: https://www.validere.com/
- Docs: https://docs.validere.com/ (App API, Data API, Transactions API)
- API base: https://api.validere.io
- Backed by: greylock, wing-venture-capital

This repo carries the APIs.json profile (`apis.yml`) plus harvested artifacts: OpenAPI specs (CarbonHub App API, Data Platform Source API), authentication profile, error catalog, conventions, lifecycle, conformance/compliance, data model, llms.txt, well-known probes, domain security, trust center, a candidate MCP tool list, and generated agent skills.
